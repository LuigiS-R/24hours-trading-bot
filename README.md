# 24 시간 주식 자동 거래 시스템

웹소켓을 통해 실시간 시장 데이터를 수신하고 이를 뉴스 센티먼트 분석 모델과 시장 행동 분석 모델에 전달하도록 구현했습니다. 각 모델의 추론 결과를 기반으로 시장 상황을 분석하고, 사전에 설정한 투자 전략에 따라 자동으로 거래를 수행합니다.
